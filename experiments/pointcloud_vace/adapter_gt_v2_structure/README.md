# GT V2 三维框架、整栋点分布与 VACE 联合训练

每栋从实测残缺点预测一组共享端点、带类型的边和三角形表面片。点在预测表面内生成。整圈相机共享一次预测的框架和点集。VACE 在这些投影条件下生成独立 RGB 视频。数据准备可以提前在 CPU 做完。训练、恢复和正式验证由用户手动占用单卡。

## 本轮入口

```bash
cd /mnt/windowsE/chuanjun/building_wan
PY=/home/shi/miniconda3/envs/scj/bin/python
ENTRY=experiments/pointcloud_vace/adapter_gt_v2_structure/scripts/run.py
RUN=outputs/pointcloud_vace/adapter_gt_v2_structure/run_20261120_044354

# 可重复运行的 CPU 准备
CUDA_VISIBLE_DEVICES='' "$PY" -Bu "$ENTRY" prepare --run "$RUN"

# GPU 空闲时手动启动。远程使用时可在 tmux 中执行
"$PY" -Bu "$ENTRY" start --run "$RUN"

# 在另一个终端查看进度或在一个更新边界暂停
"$PY" -Bu "$ENTRY" status --run "$RUN"
"$PY" -Bu "$ENTRY" pause --run "$RUN"
"$PY" -Bu "$ENTRY" resume --run "$RUN"

# 完成三轮后，按需选择续到五轮
"$PY" -Bu "$ENTRY" resume --epochs 5 --run "$RUN"

# 手动生成原八栋的正式视频
"$PY" -Bu "$ENTRY" validate --run "$RUN"
# 若验收五轮权重则加 --epochs 5
```

GPU 锁与 V2 训练和现有 VACE 流程共用。卡忙时立即返回。Ctrl+C 和 `pause` 均在更新边界保存。验证暂停后再次执行同一条 `validate`。已经核验的成片可以复用。采样由独立进程完成，其退出后释放 GPU，CPU 进程再计算指标和报告。第一个正式更新成功时写 `first_update.json`，其中包括三个参数组的变化、损失、显存和恢复点。训练进度以 `progress.json` 的已完成与已保存计数为准。

## 数据和训练

- 训练仅使用冻结清单的 10,747 栋，种子 20261120。每栋每轮一个 17 帧连续窗，落在 000–079。五轮排程预先固定，前三轮默认训练 32,241 次更新，续两轮后是 53,735 次。正式留出集为 358、2825、5954、4850、3538、2016、6485、5466。每轮记录这八栋的固定加噪窗口指标，供判断是否续跑。
- 完整 OBJ 共面三角形归并后，提取屋脊、屋谷、檐口与台阶、墙角。共享端点使每条线段保持笔直。分叉与不同坡面保留独立连接。稀疏观测预测最多 96 个候选角点和 64 个三角形表面片。单栋结构标签超过角点容量时，训练优先监督较长的结构边。完整几何点监督和评测仍覆盖所有边与表面。
- 按三角形面积内坐标生成最多 4,096 个带小幅法向偏移的候选点，并学习预测显示预算。点集分布直接对齐原始完整 GT PLY 及 GT 视频的固定点子集。原 832×480、0.75 像素半径及 4×4 抗锯齿源片保留后方散点可见性。条件投影保留两层的累计信息、深度统计和面语义。边投影只作为模型条件。VACE 是成片的唯一生成来源。
- 初值使用原 V2 三轮 Adapter 与 rank8/alpha8 VACE 注意力 LoRA，冻结骨干和原 VAE。单卡 batch 1，BF16 前向、FP32 参数，AdamW、梯度裁剪 1、无权重衰减。新分支、V2 Adapter、原 LoRA 的峰值学习率为 1e-4、3e-5、1e-5，256 步预热，前三轮降至峰值的 20%。第 4–5 轮从该学习率继续降至峰值的 10%，保留 AdamW、随机状态和排程游标。
- 各窗使用区域均衡 Flow Matching、框架拓扑和三维点分布监督。每 8 次更新一次 224×224 固定视窗可反传解码，另外监督点芯和背景亮度、点纹色度、多尺度密度、近帧及间隔 8 和 16 帧的可测同点亮度变化。GT 图像仅用于训练目标、像素监督和推理后的评分。推理条件取冻结相机、实测点、残缺视频以及模型自身预测。
- CPU 一次准备固定排程、实测几何与 GT 标签并分别存放。磁盘预取最多 4 窗，并行解码和准备即将使用的窗口。在线复用官方整帧 BF16 VAE 编码，NVMe 滚动保留至多一个 64 更新检查点间隔的 latent。普通步使用已验证的轻量 VACE 控制输出路径。需要 RGB 反向的批次启用 VACE/DiT 和解码器重算。GPU 实际吞吐及峰值待首次运行测量。

## 验收和产物

只在正式训练终点生成原八栋的 81 帧预测。采样规格为 30 步、CFG 5、shift 5、16 fps、seed 20261018。复用现有逐值核对的采样加速。最终目录含八条独立预测、八条三栏对比和一份报告，权重和恢复点在 run 的独立子目录。

报告同时给出真实 GT 结构边的检出和位置误差、RGB 可测屋脊的偏移和直度、跨帧亮度变化、屋顶首尾差、点芯、色差、局部疏密和墙面覆盖。可辨认结构的漏检仍计入分母。另有两栋完整 GT 经过冻结 VAE 的参照。视频的二维指标和内部三维点数分别记录。当前验收范围为原八栋。

前三轮完成后可查看 `epoch_2_review.json` 和 `epoch_3_review.json`。只有结构、密度与偏色仍共同改善时，才值得占用 GPU 续训两轮。若这些指标停滞，先以正式视频的屋脊和点纹确认瓶颈。
