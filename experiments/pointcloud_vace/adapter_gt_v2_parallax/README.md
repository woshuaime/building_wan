## 训练与交付

- 原划分 10,747 栋 × 三轮，每栋每轮一个 17 帧连续窗，共 32,241 次正式更新，batch/累积均为 1。每栋在 80 个唯一机位上循环，原 RGB 排程依次偏移 13 帧。原生 832×480，BF16 骨干、FP32 增量，原 rank/alpha 8/8 与新 AdamW。
- 训练入口复用相邻 V2 实验的 `scripts/train_rgb.py`。原 128 个锚点的深度插值按有效权重归一化；全部已显示实测点按原相机投影至相邻四个 4 px 小格。每层记录软计数和按计数加权的平均深度。4 个时间槽 × 16 个小格 × 4 通道经零初始化的 256→64 投影加入 V2 token，增加 16,384 个参数。训练与 81 帧推理复用同一构造。
- 原 GT 用于 17 帧 FM。实际 sigma 在 [0.10,0.60] 时复用已有预测的两个因果 latent，解码窗口前五帧。颜色/覆盖、去均值归一化点对、已知点、屋脊、短时系数依次为 .05/.03/.02/.10/.02。已知足迹以暗度加权；边缘允许加深，点芯守住渲染色，容差 3/255。结构带按需生成。原观测与完整 GT 分别采样，已知点保持是附加的弱约束。
- 普通更新沿用快速前向，RGB 更新为 DiT 与 VACE 启用梯度重算，VAE 权重冻结而解码保留梯度。四窗 CPU 预读。首步强制命中 RGB，`first_update.json` 记录实际参数变化与显存；下一个自然出现的普通步记录到 `first_fm.json`。两者均计入正式预算。
- 原八栋各生成同相机、seed 20261018、81 帧、30 步的原生视频，复用已有同一步 CFG 加速。交付位于 run 的 `交付/`，包括两份最终权重、按栋分组的原片与三栏片，以及一份合并报告。报告也归档至 `upload/`。与两版旧成片配对统计屋脊、颜色、背景、等暗量缺口点纹、首尾差和前后层四帧间隔的差分位移。固定点对跟丢计入分母，残缺输入单列为跟踪参照。2825 折脊和 358 后墙另用局部标准化图块比较缺口运动与前层运动。
