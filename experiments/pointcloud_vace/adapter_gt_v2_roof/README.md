# GT V2 屋顶增量与联合 LoRA 短对照

本组从 GT V2 的最终 Adapter 和 LoRA 出发。屋顶分支只从已观测显示点估计平面法向并沿原相机投影，使用稳定楼内 XYZ、子格密度和 V2 的八视图条件生成原始 RGB 视频。GT 和 OBJ 用于训练的屋面密度监督及推理完成后的评价。原 V2 数据、训练划分和已有八栋成片继续作为基线。

固定种子 20261120。1,024 栋使用连续 17 帧、832×480、BF16 整帧 VAE、batch 1。先准备 640 窗，再训练共同的 512 步。两路继续使用相同的 128 窗、噪声和屋顶 AdamW 状态，其中联合路以 1e-5 更新现有 VACE 自注意力 q/o LoRA，屋顶分支的学习率为 1e-4。2825、5954 两栋各比较两条 81 帧预览，与原 GT 的屋顶疏密和时间变化距离及墙面 IoU 决定分支。选中路径使用剩余 384 窗到 1,024 步，总计 1,152 次真实更新。

缓存使用本机 NVMe，并行用 CPU 准备即将编码的窗口，复用冻结的八视角几何 tokens。GPU 使用原全帧编码、关闭梯度重算和此前实测的 VACE 直接偏置路径。屋顶增量从首个 VACE 控制块注入。原 VAE 会对两栋 GT 做整帧编解码诊断。最终在同八栋、同相机、81 帧、30 步、CFG 5、种子 20261018 的设置下验证。成功交付为最终权重、一份报告、八条独立 Prediction 和八条三栏对照。工作缓存和过程检查点在成功结束时清除。
