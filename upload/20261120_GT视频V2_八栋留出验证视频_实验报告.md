# GT 视频 V2 三轮权重的八栋留出建筑 81 帧验证报告

## 当前交付（2026-11-20，东京）

本组用 10,747 栋训练建筑的三个不同 17 帧窗口训练八视角 Adapter 和 VACE 注意力 LoRA，共 32,241 次 AdamW 更新；三轮平均损失依次为 0.040020、0.037004、0.036319。每份最终权重均通过 SHA-256 和张量读回核验。8 栋留出验证的中栏展示原始预测。模型能填出部分轮廓，但点纹经常连成面片，屋檐形成粗暗边；2825 的结果尤其容易看出这个问题。稀疏点的外观还没有达到 GT 的水平。

本组 run 现交付一份《实验报告》、`交付_训练完成/` 中的最终 Adapter 和 LoRA、`验证视频_八栋_20261119/` 中的 8 条三栏 MP4。正式训练报告保存在项目的 `upload/20261119_GT视频V2_三轮全量微调_训练完成报告.md`。训练中产生的缓存、过程权重、优化器恢复点、测速、日志和过程脚本已实际清理。后续验证从最终权重和原数据读取。

**播放修正。** 原交付使用全范围 H.264 RGB 4:4:4。在用户的预览截图里，输入和 GT 的灰底一起变成了粉色，深灰标题变成绿色。旧片按 RGB 解码时，2825 第 1 秒的输入及 GT 背景均为 RGB (240, 240, 240)，标题为 (24, 24, 24)。本次在 CPU 上从当时的无损三栏原片重新编码，采用 8 位 H.264 High、yuv420p、BT.709、电视范围和 CRF 10。8 条沿用原文件名、2496×512 画布、16 fps、每条 81 帧，总计 59,667,140 字节。没有新增模型采样。

全部 648 帧均已解码，并与对应的旧片逐帧对齐；旧片的左右参考栏亦与原始数据逐像素对齐。新旧片 RGB 比较，每栋全画面 99% 的通道数值绝对差不超过 4/255，中栏各栋平均绝对差为 1.11–1.53/255。普通播放编码会带来微小数值变化。另用 Firefox 播放全部 8 条，在每条的 1、2.5 和 4.875 秒取样，24 组画面的左右栏背景都是 (240, 240, 240)，标题都是 (24, 24, 24)。现场未接入用户的 Windows 预览器。下文的模型误差指标、无损对照和成片大小记录的是修正播放格式前的原始评测。

前一阶段已用 10,747 栋训练建筑完成 3 轮、32,241 次更新。本次观察最终权重能否从一圈残缺视频与实测点几何恢复有点间空隙的完整建筑外观。验证建筑和训练建筑按 ID 隔离。模型生成了较完整的屋顶及墙体外轮廓，部分位置也形成了明显的网格状纹理、深色厚边及独立点难以辨认的连片区域。与原始残缺图相比，8/8 栋预测的二维占据网格更接近 GT。八栋的全图灰度 MAE 均比原输入更高。下文分列轮廓覆盖、点纹、首尾和颜色，以便核对这些现象。

- **选例**。将 905 栋按输入视频的实测显示点数、数值建筑 ID 排序，均分 8 组，组内取中位排名（偶数组取靠前一个）。排名依次为 57、171、284、397、510、623、736、849。该选择覆盖显示点数量区间，缺损程度、建筑类型和复杂度未作分层。原数据的显示点预算上限为 4,096，最后一个分组内会有并列。

## 涉及全部 648 帧的二维测量

将每帧 832×480 的中栏转为 R/G/B 的算术平均灰度，灰度小于 220 记作较深的点纹像素。8×8 分块里至少有一个此类像素则计作占据。对整条视频累计占据网格交并集后算 IoU。该值能反映两幅稀疏点渲染的大体覆盖范围，但网格内点的位置、数量和粗细仍会不同。MAE 以 0–255 灰度单位表示。“GT 深色 MAE”只在 GT 灰度小于 220 的像素上计算。末列使用 RGB 三通道原值计算同一输出的第 000/080 帧全图 MAE。表中斜线前为原输入对 GT、后为模型输出对 GT。

## 逐栋观察

每栋对齐检查 000、020、040、060 四个相机角度，共 32 组原输入、预测、GT 三栏静帧。重点看建筑轮廓、屋檐、墙面和点间空隙。以各条视频的全部 81 帧计算上面的二维统计。

- **358**。输入墙面仅剩少量点。四角度的预测补出墙面和山墙轮廓，000 右斜檐形成很深的连续带，020 和 060 侧边明显发黑。正墙上的点有规则行列，GT 同处点距更不均匀。
- **2825**。输入长边下方有大面积空白，预测在 000 和 040 恢复了长墙覆盖。檐线变成厚黑边，两端 020 与 060 出现收窄或弯折的深边，GT 对应轮廓由更均匀分散的灰点构成。
- **5954**。040 的内凹转角和两段墙体在预测中可辨。000 的转角上方形成一块突兀的深色竖片并接上粗檐线，GT 同位置未出现同样强烈的矩形暗块。
- **4850**。预测为缺点的侧面补出连续墙形。000 斜屋檐中部多出明显的细暗竖线，020 和 060 顶边较粗，墙面形成有方向的重复点纹。
- **3538**。输入保留主要斜屋脊，预测恢复左右墙面。000 在近右屋面下方形成突出的斜暗带与竖向折边，040 与 060 的墙面较淡，GT 中和墙面边缘的对比更均匀。
- **2016**。预测能区分多个高低体块，000 右侧平台和屋面交接处呈较厚暗条。040 和 060 屋檐、分层转折处色差被放大，中央点纹有行列感。
- **6485**。四个角度都保留狭长体形和沿长边延伸的屋顶，020 右端出现深色的台阶状上沿。顶线比 GT 更粗，立面上能看到规则成排的纹理。
- **5466**。输入正墙和底部有明显断缺，模型补出了这些部位的覆盖。000 出现较粗的内侧斜线，040、060 墙体偏淡，点纹比 GT 更规则。该栋 GT 深色区域 MAE 从原输入 73.79 升到预测 76.58，是八栋中唯一该项上升的样例。


## 使用这些视频判断下一步

八个留出样例中，模型在原本空白的墙面区域生成了更完整的二维覆盖。轮廓、面内点纹和闭环一致性仍需分别看。当前证据覆盖 905 栋验证集的 8 栋、每栋一个种子。训练模型产出 RGB 视频，画面点纹没有可追踪的三维 ID。首尾 MAE 也只量化两帧差异。此次未进行实时播放、跨帧同点跟踪、三维重建或三维精度验证。若后续关注外观，优先复核高误差样例的屋檐暗条、背景偏亮和网状点纹。若关注几何补点，则需有可验证的三维输出与对应指标。
